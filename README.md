# DRP Goiana — RF03 e RF04

Mapa de famílias em Goiana, com identificação do representante, cores por risco, agrupamento e mapa de calor. React, Next.js e TypeScript.

[**Acessar o site**](https://wesleyttiago.github.io/goiana-defesa-civil-mapa/)

Demonstração com dados fictícios. RF03 e RF04.

O campo opcional `nomeRepresentante` identifica a família. Fontes antigas continuam compatíveis. O calor mantém a escala de intensidade e acompanha o zoom da cidade.
