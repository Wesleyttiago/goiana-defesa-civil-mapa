# DRP Goiana — Gestão em campo

Cadastro de famílias com localização, mapa interativo, consulta e mapa de calor. React, Next.js e TypeScript.

[**Acessar o site**](https://wesleyttiago.github.io/goiana-defesa-civil-mapa/)

Demonstração com 500 famílias fictícias na sede de Goiana, em áreas suscetíveis do SGB e dentro do limite municipal do IBGE. Consulta de integrantes com idade, parentesco e identificação demonstrativa. Novos cadastros de teste ficam nesta aba e são apagados ao atualizar a página.

Camadas públicas: chuva e rios (APAC) e cartografia territorial de Goiana (SGB, 2025) e setores históricos (SGB, 2014). Planejamento de visitas com seleção manual de áreas.

`npm ci` · `npm run dev` · `npm test` · `npm run build`
